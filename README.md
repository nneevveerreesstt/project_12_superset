# Проект Дашборд трендов игрового рынка в Superset
## Бизнес-контекст

Игровая компания пригласила BI-аналитика для разработки дашборда, отслеживающего тренды на рынке игр. Дашборд предназначен для:
- топ-менеджеров - оценка потенциала новых релизов и корректировка ценовой политики;
- коллег-аналитиков - анализ эффективности отдельных игр и поиск точек роста.

Данные охватывают период 2007–2025 гг. и включают информацию о ценах, играх, игроках, установках и достижениях.

---

## Цель проекта

Связать данные из шести таблиц в единый датасет и построить многостраничный дашборд в Apache Superset для анализа цен, пользовательского интереса и вовлечённости игроков.

---

## Источники данных

- **Prices** - история изменения цен в разных валютах.
- **Games** - справочник игр (платформа, разработчик, издатель, жанр, языки, дата релиза).
- **Players** - данные об игроках.
- **Players_games** - установки игр игроками.
- **Achievements** - достижения в играх.
- **History** - история получения достижений.

---

## Структура дашборда

### Страница «Игровые достижения»
- Общее количество достижений.
- Средний процент редких достижений по жанру.
- Количество достижений в каждой игре.
- Количество достижений по жанру и платформе.

### Страница «Анализ игроков»
- Уникальные игроки, установки за период.
- Распределение игроков и установок по странам и платформам.
- Топ жанров по установкам.
- Распределение игроков по играм и платформам.
- Изменение количества игроков YoY по платформам (Jinja).

### Страница «Стоимость игр»
- Средняя стоимость игры в рублях.
- Средняя и медианная стоимость по жанру.
- Динамика средней цены по платформам.
- Изменение цен в процентах по играм.

### Страница «Анализ игр»
- Количество игр и релизов за период.
- Распределение игр по жанрам и платформам.
- Календарь релизов.
- Количество компаний-разработчиков и издателей.

---

## Фильтры

- Период (по умолчанию: 2024-06-01 - 2025-01-01)
- Гранулярность (по месяцам)
- Платформа, жанр
- Разработчик, издатель
- Название игры, поддерживаемые языки
- Месяц для YoY-анализа (Jinja, 2024-12-01)

---

## Ключевые метрики

| Метрика | Описание |
|---|---|
| `median_rub_price` | Медианная цена в рублях |
| `avg_rub_price` | Средняя цена в рублях |
| `achievement_amount` | Количество достижений |
| `rare_achievement_share` | % редких достижений |
| `developers_amount` | Количество разработчиков |
| `publishers_amount` | Количество издателей |
| `games_amount` | Количество игр |
| `players_amount` | Количество игроков |
| `installs_amount` | Количество установок |

---

## Стек технологий

- **Apache Superset** - дашборд, чарты, фильтры, кросс-фильтрация, Jinja.
- **PostgreSQL** - источник данных.
- **SQL** - объединение таблиц и расчёт метрик.

---

## Ключевые результаты

- Создан единый датасет на основе шести таблиц.
- Разработан дашборд из четырёх страниц с логичной структурой.
- Настроены фильтры, кросс-фильтрация и Jinja-метрика для YoY-анализа.
- Дашборд готов к использованию для оценки релизов, цен и вовлечённости игроков.
